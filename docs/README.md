# Документация rustore-mcp

`rustore-mcp` — MCP-сервер (stdio или HTTP) и CLI для RuStore API. Краткое описание и быстрый старт — в [README](../README.md).

| Страница | О чём |
| --- | --- |
| [Установка и обновление](install.md) | Установочный скрипт, Homebrew, готовые архивы и `SHA256SUMS`, Windows, сборка из исходников, платформы, удаление. |
| [Подключение к MCP-клиентам](clients.md) | `connect` для Claude Code и Codex, ручное подключение других клиентов (Antigravity, Kimi Code, ZCode и любых со stdio), профили, отключение. |
| [HTTP-режим](http.md) | `serve --http` для удалённых клиентов и контейнеров: ключ RuStore API на сервере, токены доступа клиентов, Docker, Compose, systemd, подключение клиентов. |
| [Справочник CLI](cli.md) | Все команды и флаги: `connect`, `serve`, `auth` (в том числе `auth check`), `key exec`, `tools`; профили, ключ RuStore API и переменные окружения. |
| [MCP-инструменты](tools.md) | Как генерируются инструменты, уровни доступа, наборы, частые задачи (выпуск версии, раскатка, отзывы, тексты карточки, скриншоты, платежи), составные инструменты, аргументы и ответы, постраничная выдача, `api_search`, `api_request`, фильтр `jq`, пользовательские инструменты. |
| [Безопасность](security.md) | Хранение ключа RuStore API и токена, права ключа и их проверка, `key exec`, уровни доступа и действия уровня удаления, вырезание учётных данных из ответов, доступ к локальным файлам, протокол и логи. |
| [Решение проблем](troubleshooting.md) | Homebrew tap, Keychain, Secret Service в Linux, SSH, формат ключа, отказ RuStore в ключе и `403`, большие ответы. |
| [Разработка](development.md) | Структура крейтов, проверки, сборка и clippy для Windows, пересборка спецификации API. |
